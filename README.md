## 🚘 Tentang Project

**Digital Twin Smart Parking** merupakan konsep sistem yang membuat representasi digital dari area parkir nyata.

Sistem menggabungkan **miniatur area parkir, sensor, mikrokontroler, database, dan dashboard web** untuk menampilkan kondisi slot parkir secara digital.

### 🔄 Konsep Sistem

**Area Parkir Nyata**
    ↓
**Sensor Kendaraan**
    ↓
**ESP32 / Arduino**
    ↓
**Wi-Fi**
    ↓
**Database**
    ↓
**Digital Twin**
    ↓
**Dashboard Smart Parking**

## 💡 Fitur Utama

* 📍 Monitoring lokasi parkir
* 🚗 Deteksi kendaraan
* 🅿️ Informasi slot kosong dan terisi
* 🚦 Indikator status parkir
* 📊 Statistik penggunaan parkir
* 🕐 Riwayat kendaraan masuk dan keluar
* 🌐 Dashboard berbasis web
* 🔄 Sinkronisasi data kondisi fisik dengan representasi digital
